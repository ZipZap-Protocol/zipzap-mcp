          Exposed MCP Tools
        

        
Callable by any agent via standardized JSON-RPC messages.

      


      

        
        

          

            zipzap_get_quote
            Routing
          

          

            Fetches optimal split swap quotes across DEXs on EVM or Solana. Calculates expected output, price impact, and fee breakdown.
          

        


        
        

          

            zipzap_build_swap_tx
            Execution
          

          

            Constructs unsigned EVM calldata for ZipZapRouter.swap() or serialized Solana VersionedTransaction.
          

        


        
        

          

            zipzap_get_wallet_balance
            State
          

          

            Reads native ETH/KAIA/SOL and ERC20 or SPL token balances directly from decentralized RPC endpoints.
          

        


        
        

          

            zipzap_get_tokens
            Registry
          

          

            Returns verified token mints, symbols, decimals, and contract addresses across all supported chains.
          

        


        
        

          

            zipzap_get_chains
            Discovery
          

          

            Discovers active chain IDs, block explorer URLs, canonical wrapped native addresses, and active RPC providers.
          

        


        
        

          

            zipzap_crosschain_quote
            Bridges
          

          

            Plans atomic multi-hop swaps across disparate networks via LayerZero and Stargate bridge relays.
